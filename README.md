# 📊 Customer Churn & Retention Analysis (Power BI)

## 📌 Overview
This project analyzes customer churn behavior in a SaaS business using Power BI.

The goal is to understand:
- Why customers leave
- Which segments are at risk
- How retention can be improved

---

## 📈 Key Metrics
- Total Customers: 500
- Active Customers: 390
- Churned Customers: 110
- Churn Rate: 22%

---

## 🔍 Key Insights
- ~22% customers churned (1 in 5)
- Churn is increasing over time
- Higher churn in Pro & Basic plans
- Main reasons: budget, competition, missing features
- DevTools & FinTech show higher churn
- ~78% users still active (retention opportunity)

---

## 📊 Dashboard Features
- KPI cards (Total, Active, Churned, Churn Rate)
- Churn trend over time
- Churn by plan tier
- Churn by industry
- Top churn reasons
- Customer distribution (Active vs Churned)

---
